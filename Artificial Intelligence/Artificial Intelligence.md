# Artificial Intelligence

The practices and concepts of the field: data science, machine learning and deep learning. Each family below has its own map.

- [[Artificial Intelligence/Generative Modeling/Generative Modeling|Generative Modeling]]: models that learn a distribution and draw new samples from it.
- [[Machine Learning]]: Machine learning fits a model to data by choosing the parameters that make a loss small.
- [[Deep Learning]]: Deep learning stacks many learned layers into one network.
- [[Large Language Models]]: A large language model is a transformer trained to predict the next token of text.
- [[Attention]]: Attention scores a query against every key, turns the scores into softmax weights, and returns the weighted sum of the values.
- [[Backpropagation]]: Backpropagation computes the gradient of a network's loss with respect to every weight by applying the chain rule backward from the loss, one layer at a time.
- [[KV Cache]]: The KV cache stores the attention keys and values of every token already processed, so each new decoding step computes them only for the newest token.
- [[Retrieval-Augmented Generation]]: Retrieval-augmented generation looks up passages relevant to a question in an outside store and puts them in the model's prompt, so the answer can draw on them.
- [[LLM As A Judge]]: LLM-as-a-judge uses one language model to grade another model's answers against written criteria, in place of a human grader.
