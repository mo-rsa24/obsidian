**The journey's goals** live at `/home/molef/goal-setting/learning/system-design/foundations/`.

**The code** lives at `/home/molef/playground/system-design/request-path/`, a toy copy of a corner shop's request path in Docker Compose. That folder is scratch and can be deleted at any time, so anything worth keeping from a session gets written here instead.

**What it is for.** Bring the whole path up from an empty folder, send one order, and follow it hop by hop from DNS to the worker, with each hop timed, broken once on purpose, and explained.
