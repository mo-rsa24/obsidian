# Information Technology

Information Technology. Things with a version you install, such as [[Docker]] and [[Redis]], are under [[Software]].

**Information technology is how computing works underneath the tools: how machines talk, how data is stored safely, how a service is designed, secured and run. Nothing here has a version number to install.**

- [[Networking]]: Networking is how one machine's request reaches another and the answer comes back.
- [[Database Systems]]: A database system stores data so many users can read and change it at once without losing or corrupting it.
- [[Concurrency]]: Concurrency is a system making progress on many tasks or requests in overlapping time, switching between them while each waits, whether or not any two run at the same instant (running at the same instant on separate cores is parallelism).
- [[Security]]: Security is how a system knows who is calling, decides what they may do, and keeps data unreadable to anyone else.
- [[System Design]]: System design is choosing the parts of a service and how they talk so it stays fast and correct as users grow.
- [[DevOps]]: DevOps is the practice of building, shipping and running software as one loop.
