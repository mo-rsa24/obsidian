# Software

Things with a version number you install or import, grouped by the family their documentation puts them in.

- [[Python]]: the Python language and its libraries.
- [[React]]: the JavaScript library for building user interfaces.
- [[Django]]: Django is a Python web framework that answers each request by matching its URL to a view, which reads and writes models through its ORM and returns what a template or a serializer builds: the model-view-template pattern.
- [[Docker]]: Docker packages an application and its dependencies into an image, built from a Dockerfile, and runs that image as a container: an isolated process sharing the host's kernel, with Docker Compose starting several of them together.
- [[Kubernetes]]: Kubernetes runs containers across a cluster of machines and keeps the cluster at the state its manifests declare: a control plane schedules pods, the smallest unit of one or more containers, onto worker nodes and replaces them when they fail.
- [[Redis]]: Redis is an in-memory key-value data store, used as a cache, a counter store, a message broker and sometimes a database, fast because its data lives in RAM.
- [[Nginx]]: Nginx is a web server that is mostly used in front of other servers, as a reverse proxy, load balancer, cache and TLS terminator, handling many connections at once with a few event-driven worker processes.
- [[Apache Kafka]]: Apache Kafka is a distributed event streaming platform: producers append messages to ordered, partitioned topic logs kept on a cluster of brokers, and consumer groups read them at their own pace by offset, able to replay from any point.
- [[SQLite]]: SQLite is a relational database engine that runs inside the application as a library and keeps the whole database in one file, with no server process to start.
- [[Vite]]: Vite is a JavaScript build tool and development server that serves source files to the browser as native modules while you develop, proxies chosen paths to a backend, and bundles the app for production.
- [[Sentry]]: Sentry is an error-tracking service: an SDK in the application sends each unhandled exception with its stack trace, and Sentry groups repeats into one issue and alerts the team.
- [[OpenStreetMap]]: OpenStreetMap is a free, community-built map of the world; its Nominatim service turns addresses into coordinates and back, and its tile servers draw the map.
